# Новостной портал

## Описание проекта

Это веб-приложение — новостной портал, разработанный на Django. Проект включает систему аутентификации пользователей, управление персональными новостями и красивый интерфейс с Bootstrap.

**Это практическое задание для группы 23МКН.** Проект демонстрирует работу с Django ORM, аутентификацией, формами, шаблонами и статическими файлами.

## Функционал

- **Регистрация и аутентификация**: Регистрация новых пользователей, вход/выход, редактирование профиля, удаление аккаунта.
- **Управление новостями**:
  - Просмотр всех новостей с пагинацией.
  - Добавление, редактирование и удаление только своих новостей.
  - Проверка прав доступа (нельзя редактировать чужие новости).
- **Интерфейс**: Адаптивный дизайн с Bootstrap, анимации, иконки Font Awesome.
- **Админ-панель**: Доступна для суперпользователя по адресу `/admin/`.

## Технологии

- **Backend**: Django 4.2.7
- **Frontend**: HTML, CSS (Bootstrap 5), JavaScript
- **База данных**: SQLite (по умолчанию)
- **Дополнительно**: Font Awesome для иконок

## Установка и запуск

### Предварительные требования
- Python 3.8+
- Git

### Шаги установки

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/b2sj8j4t74-code/portal.git
   cd portal
   ```

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Выполните миграции**:
   ```bash
   python manage.py migrate
   ```

4. **Создайте суперпользователя** (опционально, для админки):
   ```bash
   python manage.py createsuperuser
   ```

5. **Запустите сервер**:
   ```bash
   python manage.py runserver
   ```

6. **Откройте браузер**: Перейдите на http://127.0.0.1:8000/

## Использование

- **Главная страница**: Список новостей с пагинацией.
- **Регистрация**: Создайте аккаунт для добавления новостей.
- **Добавление новости**: Только для авторизованных пользователей.
- **Редактирование/удаление**: Доступно только автору новости.
- **Профиль**: Просмотр и редактирование личных данных.

## Деплой

- `requirements.txt` содержит зависимости для Django REST Framework, фильтрации, Gunicorn, WhiteNoise и Postgres/Heroku-style DATABASE_URL.
- `Procfile` и `bin/start.sh` подготовлены для запуска на Render.
- Настройки читают `SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS`, `DATABASE_URL` из окружения.
